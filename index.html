Research focus

My doctoral research applies machine learning to two very different problems in clinical decision-making: diabetes epigenetics and cardiac imaging.

The first strand used Elastic Net models to identify DNA methylation patterns that distinguish type 2 diabetes from healthy liver tissue. The models performed well internally, but the same patterns didn't hold up in an independent external dataset — a result that says as much about the limits of generalisability in epigenetic machine learning as it does about diabetes itself, and part of why I now build tools focused on honest model evaluation rather than headline accuracy.

The second strand used deep learning (nnU-Net) to segment the left ventricle from echocardiograms across three standard views, then developed two new methods for measuring the left ventricular posterior wall directly from the resulting masks. Segmentation of the ventricle itself was consistently strong; the wall, and the measurements built on top of it, proved harder — revealing a tendency to overestimate wall thickness and a sensitivity to how the mask was shaped. Both strands point to the same lesson, and it's the one behind the tools below: a model that looks good on its own training data still has to earn trust on new data and against a clinically meaningful bar.

Projects

clineval

Python library + app

A tested Python library and interactive Streamlit app for evaluating binary clinical prediction models properly: calibration curves, Brier score, discrimination (AUROC/AUPRC with bootstrap confidence intervals), and decision curve analysis. Includes a paired comparison mode for testing whether one model is meaningfully better than another on the same patients, with cluster-aware resampling for longitudinal data, plus live PubMed/ClinicalTrials.gov lookups for comparable published models.

Omics Explorer

Python app

A generic, deployable dashboard for exploring any tabular omics dataset — transcriptomics, proteomics, metabolomics, or anything else shaped like features by samples. Upload your own data or try the built-in demo: preprocessing, PCA and clustering, and differential analysis with an interactive volcano plot, all without writing code.
